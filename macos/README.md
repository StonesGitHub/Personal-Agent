# 墨知 Mac 0.2.0

独立 Mac 桌面客户端，连接现有墨知 Agent 服务。支持 macOS 12 及以上，构建为 Apple Silicon / Intel 通用应用。

## 首次使用

1. 将磁盘映像中的「墨知」拖入 Applications。
2. 在「我 → 连接设置」填写你自行部署的 HTTPS 服务地址以及管理后台发放的**个人服务凭证**。如反向代理包含路径前缀，填写完整 API 根地址。这里不接受模型 API Key。
3. 验证账号后开始墨聊。`⌘N` 新建，`⌘Enter` 发送，`⌘,` 打开连接设置。

## 已实现

- 桌面侧栏、会话历史搜索、Markdown / 表格 / 代码块、安全链接、原生文件下载与 Markdown 导出。
- 服务端任务提交、持续查询、重启恢复查询、取消、中断后主动继续、执行记录、服务端任务分页与结果查看。
- 请求编号与完整待提交内容先加密写盘，失联时只查询。用户点击「重试同一请求」使用原编号和原内容，不自动新建计费任务。
- DOCX、XLSX、PNG/JPEG/GIF/WebP 原生选择上传，每条最多3份、每份8MiB。旧版 DOC/XLS 需转换。图片识别能力取决于服务端视觉模型配置，上传阶段即可产生识别费用。成功上传的提取结果按服务端现有规则保留；移除待发送附件不会删除服务端已有提取结果。
- 本机背景、回复反馈、可编辑的本机发现问答、手动决定记录、服务端提醒和健康观察查看。
- Keychain 保存服务凭证；CryptoKit AES-GCM 加密本机记录。按服务地址及服务端用户 ID 隔离数据，切换账号不会混合对话。原始附件不在 Mac 客户端复制留存。
- 关闭窗口时进程保留，可从 Dock 重新打开；退出 App 后服务端已接收的任务仍执行，下次打开查询结果。

## 当前范围

- 与本仓库的服务端配套使用；支持手机号登录、附件、任务和账号备份接口。
- 服务端任务列表不返回完整的请求聊天历史。Mac 本机对话、背景、决定、发现**不自动同步手机**；同一账号可查询各端已提交的服务端任务结果。
- 发现为明确标注的本机收藏，无多人社区、点赞计数或评论冒充。决定由用户确认后保存，不把助手建议直接当成用户选择。
- 可取回已上传的手机账号快照，具体范围见 [PHONE_ACCOUNTS.md](../PHONE_ACCOUNTS.md)。暂无自动提取长期记忆、系统推送通知、定位和自动更新。提醒到期行为沿用服务端。
- 本机记录上限20MiB；单条新消息最多20000字符，历史请求按服务器预算截断较长的旧回复并标记。附件提取仍受服务端文本量限制。
- 本机加密密钥丢失时不能解密记录，不会静默创建新密钥覆盖旧文件。对话导出是用户主动选择的**明文 Markdown**，不含凭证或隐藏背景。

## 开发与构建

结构：`Sources/` 为 AppKit / WebKit 原生窗口、网络、文件选择与加密存储；`Web/` 为打包进应用的界面和业务状态逻辑。没有远程页面、CDN、Node 运行时或第三方前端依赖。所有网页网络请求禁用，桥接仅允许固定公共 API 路由，拒绝重定向转发凭证，远程 HTML 不执行。

在安装 Xcode Command Line Tools 的 Mac 上：

```bash
node --test macos/Tests/core.test.cjs
bash macos/scripts/build.sh
open macos/build/墨知.app
```

Node 仅用于测试，构建与运行应用均不需要。GitHub Actions `macOS app` 自动编译两种架构、验证并上传 `.app.zip`、`.dmg` 和校验值。

缺省为开发用 ad-hoc 签名，**没有 Apple Developer ID 公证**，下载后可能被 Gatekeeper 拦截。仅在确认来源后，通过 macOS「系统设置 → 隐私与安全性 → 仍要打开」批准该应用；不要全局关闭系统安全检查。面向普通用户分发前应在自己的 Mac/CI 配置 Developer ID 证书，用 `MOZHI_MAC_SIGN_IDENTITY` 指定证书，`MOZHI_MAC_NOTARY_PROFILE` 指定已经通过 `notarytool store-credentials` 保存的钥匙串配置。

源代码不包含开发者证书、模型密钥、用户凭证或生产数据。
