# 墨知服务 0.5.0

新增可选联网网关（搜索、网页、分享链接导入预览），与原有社区共用一个服务入口。部署 Agent 请先阅读 **[DEPLOY.md](DEPLOY.md)**，其中包含具体命令、环境变量、验收、备份和回滚。网关不接收完整聊天文件、记忆库或模型密钥；关键词和分享链接会发送到用户配置的服务。

原有社区是一个供邀请内测的共享问答服务，与手机端 Agent 独立。服务保存用户主动发布的问题、回答、点赞、评论、社区昵称与举报，不接收个人记忆库、GPS、模型 API Key 或隐藏上下文。没有预置帖子或伪造互动数。

手机端 0.4.1 默认采用本机示例和加密本地分享，无需部署本服务；仅构建时明确配置 HTTPS 社区地址才会调用本服务。内置示例与本机内容不自动上传。

## 当前完成与尚未开放

已实现持久化 SQLite、随机设备身份、问答发布/分页/详情、我的分享、点赞切换、评论分页/删除、作者删除、举报与维护者删除接口。发布和评论使用幂等键，失败重试不会重复创建。测试通过两个独立身份完成共享与互动。

**尚未部署公网服务，也没有为 Android 包配置线上地址。** 手机端 0.4.1 默认展示已标注的示例与本机分享，点赞和评论也仅本机可见。此目录是可启动和联调的服务实现，不代表多人社区已对真实用户开放。

## 本地运行与验证

Python 3.12：

```bash
cd community
python -m venv .venv
. .venv/bin/activate
pip install -r requirements-test.txt
pytest -q
uvicorn app:create_app --factory --host 127.0.0.1 --port 8090 --no-access-log
```

SQLite 默认保存至 `data/community.sqlite3`。可用 `MOZHI_COMMUNITY_DB` 指定独立持久化目录。服务重启保留帖子和互动，数据库不应提交到 Git。

## 部署接入

1. 在专用于墨知社区的服务器准备域名和 HTTPS 反向代理；使用独立数据库和程序目录。
2. 通过安全的环境配置注入随机的 `MOZHI_MODERATOR_TOKEN`，不要写入代码或 Android 包。
3. `docker compose up -d --build`。示例仅映射 `127.0.0.1:8090`，由 HTTPS 反向代理转发；数据库放在独立的 Docker volume。
4. 配置请求大小、连接超时和入口限流；若转发客户端IP，仅信任实际反向代理，不能任意信任客户端提交的 Forwarded/X-Forwarded-For。
5. 构建 Android 时设置 `MOZHI_COMMUNITY_URL=https://你的社区域名`，使用原签名密钥签名。客户端不接受 HTTP、不跟随跳转、不把社区身份发给模型地址。
6. 在两台测试设备完成发布、读取、点赞、取消、评论、删除和断网重试验收，再开放内测。

上述步骤没有在本轮自动执行部署，也没有上传任何真实聊天内容。

## API

所有响应为 JSON。写操作需 `Authorization: Bearer <设备社区token>`；读操作可以匿名，带合法token时返回当前用户的 `mine` / `liked` 状态。身份token只返回一次，服务端保存SHA-256摘要；客户端用现有本机加密设置保存。模型密钥不参与社区认证。

| 接口 | 用途 |
| --- | --- |
| POST `/v1/sessions` | 创建设备社区身份，昵称可空，自动生成“墨友xxxx” |
| GET `/v1/posts?before=&limit=&mine=` | 最新问答或当前身份的分享；返回 `next_before` 游标 |
| POST `/v1/posts` | 仅允许 `client_id`、`question`、`answer`，分别最多8000/24000字 |
| GET / DELETE `/v1/posts/{id}` | 详情；仅作者能删除自己的问答 |
| PUT `/v1/posts/{id}/like` | `liked: true/false`，同一用户最多计一次 |
| GET / POST `/v1/posts/{id}/comments` | 评论分页；提交 `client_id` 和 `text`（最多2000字） |
| DELETE `/v1/comments/{id}` | 作者删除自己的评论 |
| POST `/v1/reports` | `kind`、`target_id`、`reason`；同一用户对同一条举报去重 |
| GET `/moderation/reports` | 使用维护者密钥查看待处理举报 |
| DELETE `/moderation/posts/{id}` | 维护者删除问答及其评论/点赞 |
| DELETE `/moderation/comments/{id}` | 维护者删除评论 |

服务拒绝额外字段、空白文本、过长内容及超过150KB的请求。基础限额：同一来源每小时12个新设备身份；每个身份每小时20次发布、每分钟120次点赞操作、30次评论，每小时20次举报。限流记录保存在数据库；公网入口仍需独立限流与滥用治理。

## 内测边界

- 当前是设备匿名身份，不是完整账号体系；没有跨设备登录、账号找回、手机验证码或用户认证。客户端清除数据或卸载后，旧token无法重新推导，旧分享不会自动删除。
- 举报由维护者处理，没有宣称已具备自动内容审核、反作弊或大规模社区治理。默认不开启公网社区；开放注册前需要补齐账号恢复、封禁、内容审核与运营处理流程。
- SQLite适用于小规模单实例内测；尚未进行负载测试、生产灾备、数据库迁移或高可用部署。
- 点赞与评论使用真实持久化数据，不自动生成热度。不把问答正文当作系统指令执行，不代理抓取其中的URL；Android 使用本地 Markdown 文本渲染，不执行HTML/JavaScript。
- 分享只限一问一答，但正文可能包含用户在聊天中说过的个人信息。发布前有编辑和预览，用户决定哪些文字公开；本版没有承诺自动脱敏。

验证记录见仓库根目录 `TESTING.md`。
