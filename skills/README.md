# 墨知内置技能 0.7.0

三个技能包接入手机直连 Agent 与服务端 Agent，入口在「我 → 内置技能」。通过聊天内容自动加载，服务端也支持 `load_skill` 主动加载。内置方法可停用；自定义流程另建技能。此次没有自动接通发现社区、变更正式应用身份或部署公网服务。

| 技能 | 方法与实际工具 | 独立管理入口 |
| --- | --- | --- |
| 出游 | 时间/预算/同行人约束、行程和备选、实时信息核实、地图链接；服务端可保存行程/预算文件 | 技能卡片「开始使用」将示例放入输入框，由用户发送 |
| 定时任务提醒 | 创建/列出/修改/取消提醒，一次、每天、每周；服务端持久化、本机 AlarmManager、到期记录 | 我 → 提醒与日程 |
| 健康管理 · 中医调养与食疗 | 一般调养、普通食材方案、观察与复盘；保存/读取/删除饮食、睡眠、症状、活动、测量记录 | 我 → 健康记录，可切换本机/服务端 |

## 部署和权限

1. 更新 `server/` 的 API、管理 API、worker，同时更新 `admin/` 静态资源。仍独立构建、独立部署；没有跨目录运行时源码依赖。
2. 先用 `server/scripts/backup.py` 备份数据库。首次启动自动建新表，既有用户、任务、配置、社区数据不重写。
3. **旧用户/已有运行配置不会自动扩大工具权限**。在独立管理后台「Agent 配置」与「用户管理」两处启用所需的新工具：`load_skill`、`map_links`、四个提醒工具、三个健康记录工具。新建数据库/用户默认拥有当前全部工具。
4. 安装本次源码构建的 **0.7.0 / versionCode 14**，沿用既有对应版本的签名证书。已安装的旧 APK 不会自动获得入口或通知接收器。
5. 手机端连接公共 Agent HTTPS 根地址；「提醒与日程」中允许通知、按需要允许精确闹钟。无需新增公网端口；提醒接口使用当前用户凭证。

## 提醒语义与交付范围

- 时间规则保存绝对首次时间、IANA 时区、重复规则；不会跟随手机换时区悄悄改变原计划。每周按首次日期的星期重复。夏令时缺失时段向后平移；重复时段只触发第一次。首次日期必须在未来，最多十年。
- **当前为固定文字提醒**。到点不再次调用模型、不执行搜索、代码、邮件或短信。月度、工作日组合、条件触发、动态生成内容不是本版能力。
- 服务端 worker 每5秒处理到期提醒（与等待模型响应并行），事务保存到期事件和下一次时间，唯一约束防止重启重复。一段停机期间错过的多次重复会合并为一条到期记录，下一次从当前时间继续，不补发大量历史提醒。触发本身不消费模型 token。
- 手机在启动、回到前台、服务端任务结束、用户手动同步后获取完整有效提醒及到期记录。收到记录先写加密数据库，再确认收取；本机闹钟与服务端记录使用同一个事件编号去重。
- 手机已同步的提醒无需保持聊天界面开启、无需联网即可使用本机闹钟。**没有接厂商推送/FCM**；从另一台设备/接口新增或修改后，当前手机须再次同步。离线手机可能仍显示旧提醒。多设备共用同一凭证时，到期收件箱的确认是账户级；分别同步过的本机闹钟各自生效，不承诺全设备消息送达。
- Android通知权限拒绝、频道关闭、未允许精确闹钟、省电限制、关机或强行停止会影响显示/时间；界面显示实际权限与同步状态。应用恢复后保留到期记录，近24小时内的未通知记录可补通知；查看历史保留30天。通知的敏感正文默认不展示在锁屏公共视图。
- 一次提醒触发后完成；每天/每周继续。最多100个有效提醒。暂停用户不产生新的服务端事件；已经同步到手机的闹钟仍可能触发；服务端停用或重置凭证不能远程擦除本机缓存，清空本机数据可撤销这些本机闹钟。
- 服务端工具保存后立即生效，后续聊天失败/取消不回滚已保存的提醒或健康记录；可在管理入口查看/取消。手机直连工具改动随成功回答一起提交，失败或取消不提交。停止模型任务不等于取消提醒。

## 健康记录与边界

- 只在本轮用户明确要求记录，或点击记录表单保存时写入。提示词要求区分本人/家人、实际观察/助手建议/医生诊断；工具校验证据必须来自本轮用户原话。证据匹配是基础约束，不等于对每段自然语言意图的完美识别。
- 中医解释区分传统经验与已核实证据；普通食材用量作为烹饪份量。方法不支持自行辨证确诊、开中药剂量处方或调整处方药；儿童、孕哺期、过敏、慢病/用药背景按相关性确认。具体疾病、不确定事项应使用实际返回的权威来源；明显急症优先及时就医。
- 方法设计参考 [WHO健康饮食](https://www.who.int/news-room/fact-sheets/detail/healthy-diet) 与 [NCCIH中医介绍](https://www.nccih.nih.gov/health/traditional-chinese-medicine-what-you-need-to-know)，核对日期2026-10-08。这些参考资料不是已经为用户检索完成的个体化医疗意见。
- 健康记录最多2000条，服务端按用户隔离，返回最近30条并可翻页。关闭本次个人背景时，Agent不能调用健康记录读写工具；用户主动进入记录页面的管理操作仍可用。
- 本机观察加密保存；服务端观察存入当前 Agent 数据库，不进入发现，不进入管理后台列表。服务端健康记录/API正文不记入访问日志。删除记录不会自动擦除用户之前的聊天、已生成文件或备份中的副本。
- 本机与服务端记录不会自动双向合并。切换执行方式时需注意记录所在位置。

## 数据与备份

- 新表：`reminders`、`reminder_events`、`health_records`、`personal_effects`。沿用 SQLite 备份即可覆盖，无额外存储服务。
- 手机备份升级为v4，继续读取v1/v2/v3；新备份包含本机提醒和健康记录，不包含远程凭证或远程提醒缓存。旧版应用无法读取v4备份。
- **恢复备份后的本机提醒统一暂停**，防止旧备份重新激活已取消的提醒；可在提醒管理修改时间后启用。恢复早期备份会补齐三项内置技能，保留备份中已有技能的启停设置。
- 清空本机数据会撤销本机闹钟和通知，服务端内容须分别取消/删除。

## 技能源文件

`skills/builtin.json` 是维护源；通过以下命令生成相同的部署资源：

```sh
python scripts/sync-skills.py
python scripts/sync-skills.py --check
```

生成路径：`app/src/main/assets/builtin_skills.json`、`server/mozhi_service/builtin_skills.json`。部署时各自读取包内资源，不依赖另一项目目录。技能只能描述方法，真实权限仍由工具白名单、用户开关和服务端校验决定。新增能力需同时实现工具，不能仅在方法中宣称有权限。

测试命令和需要在实际设备上验证的项目见 [TESTING.md](../TESTING.md)。
